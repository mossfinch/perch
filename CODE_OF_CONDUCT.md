# Code of Conduct

## The short version

Be decent. Assume the person on the other side is trying, and say the useful
thing rather than the clever one.

## What that rules out

Harassment, insults, and personal attacks. Sexual language or imagery.
Publishing someone's private information. Sustained disruption of a discussion.
None of these become acceptable because the technical point underneath them was
correct.

## Scope

This applies in issues, pull requests, commit messages and anywhere else this
project is being discussed on GitHub.

## Enforcement

This is a one-person project, so there is no committee. Reports and
enforcement go through GitHub:

- To report something in this repository, use GitHub's **Report abuse** link on
  the comment or issue in question, or open a
  [security advisory](https://github.com/mossfinch/perch/security/advisories/new)
  if you would rather it stay private.
- The maintainer may edit, hide, or delete comments, and may block accounts,
  without a further explanation than this document.

⚠️ There is deliberately no contact email here. The maintainer publishes under
a pseudonym and does not keep a public inbox; GitHub's own channels are the way
through.
